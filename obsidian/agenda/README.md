# Plugin "Agenda" para o Obsidian

Envia a nota de planejamento aberta para o app Projeto Agenda, com prévia antes de importar.

## Instalar (uma vez, no PC)
1. Baixe o plugin pelo app (**Projetos → Importar plano → Botão no Obsidian**) ou copie esta pasta.
2. Extraia em `<seu cofre>/.obsidian/plugins/projeto-agenda/` (a pasta deve conter `manifest.json`, `main.js` e `styles.css`).
3. No Obsidian: **Configurações → Plugins da comunidade** → desative o "Modo restrito" (se estiver ligado) → recarregue a lista → ative **Agenda (Projeto Agenda)**.
4. Em **Configurações → Agenda (Projeto Agenda)**: confira o endereço do app e clique em **Testar**.

## Usar
- Com a nota de planejamento aberta: ícone de calendário na barra lateral, **Ctrl+P → "Enviar nota para a Agenda"** ou clique direito na nota → **Enviar para a Agenda**.
- Aparece a prévia (o que será criado/atualizado). **Importar** grava; dá para enviar de novo sempre que editar a nota (reimportar atualiza, não duplica e não apaga nada).
- Atalho de teclado: **Configurações → Teclas de atalho** → procure "Agenda".

O formato da nota é o mesmo da tela "Importar plano" (copie o modelo por lá).
O computador precisa estar com o Tailscale ligado, como para abrir o app.
